การเตรียมความพร้อม : People · Process · Technology
สิ่งที่ต้องพัฒนาในแต่ละมิติ แยกตาม Phase เพื่อให้การเปลี่ยนผ่านสำเร็จได้จริง
Phase 1 : Foundation (12–18 เดือน)
People
แต่งตั้ง Data Governance Council อย่างเป็นทางการ
กำหนด Data Owner ทุกชุดข้อมูลหลัก
กำหนด Data Steward ประจำแต่ละกอง
อบรม Data Literacy ≥ 100 คน
สร้าง Data Champion ใน สรข. ทุกเขต
Process
จัดทำ SOP ว่าข้อมูลไหล/ตรวจ/อนุมัติอย่างไร
กำหนด Standard สำหรับรายงาน สรข.
วางนโยบาย Data Retention ตามกฎหมาย
กำหนด Data Quality KPI แต่ละชุดข้อมูล
จัดทำ Hybrid Workflow (กระดาษ+ดิจิทัล)
Technology
ติดตั้ง Data Catalog / Metadata Tool
จัดทำ Data Dictionary กลาง
ปรับปรุง Data Model ระบบใบอนุญาต
กำหนด Data Standard ทุกระบบที่มีอยู่
เริ่ม Digital Archive เอกสารสำคัญ
Phase 2 : Integration (18–24 เดือน)
People
จ้าง/พัฒนา Data Engineer ภายใน
อบรม API Integration สำหรับทีม IT
ประสาน Partner หน่วยงานภายนอก (สผ./DBD)
พัฒนาทักษะ SQL/Python ทีม ศสท.
Process
MOU แลกเปลี่ยนข้อมูลกับหน่วยงานพันธมิตร
กระบวนการ Data Quality Monitoring อัตโนมัติ
Change Management สำหรับระบบใหม่
กระบวนการ Onboarding ระบบใหม่ สรข.
Technology
สร้าง API Gateway กลาง กพร.
พัฒนา Data Pipeline อัตโนมัติ
Master Data Management Platform
เชื่อม i-Single Form ครบทุกประเภทคำขอ
Digital Archive ระบบกลาง
